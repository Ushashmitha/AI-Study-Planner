# AI Study Planner

An adaptive AI-powered study planning web application designed to help students organize their academic preparation.

## Project Objective

The application generates personalized study schedules based on:

- Subjects
- Topics
- Exam dates
- Topic difficulty
- Topic importance
- Student confidence
- Study progress
- Available study time

The system can adapt the study plan based on the student's progress and missed study sessions.
